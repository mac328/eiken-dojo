## 詳しい説明（上限4000文字）

英検準2級の一次試験に必要な力を、単語から長文まで一つにまとめた学習アプリです。収録は732問。ほぼすべての英文に音声がついていて、端末の中に入っているので通信のない場所でも聞けます。

■ 収録内容

・単語 300語（英語→日本語の4択）
・熟語 90問（大問1の頻出表現）
・文法・空所補充 75問（大問1形式）
・会話文 60問（大問2形式）
・会話リスニング 80問（第1部対策）
・英作文の型 50問（意見論述・Eメール返信）
・長文読解 45問（大問3形式）
・二次面接シミュレーション 32枚

このほかに「単語リスニング」モードがあります。上の単語・熟語390語を、
文字ではなく音声で出題します。同じ語を目と耳の両方から覚えられます。

■ 間違えた問題が、忘れた頃にまた出る

正解するたびに、その問題が出るまでの間隔がのびていきます。
1分 → 10分 → 1日 → 3日 → 7日 → 14日 → 30日。

間違えた問題は間隔がリセットされ、またすぐに出題されます。「覚えたつもり」で終わらせず、忘れかけたころに出会い直す仕組みです。

ホーム画面の「復習する」ボタンには、いま出題時期を迎えている問題の数が表示されます。何をやるか迷ったときは、まずここから始められます。

■ 音声2078本を収録

すべての英文に音声がついています。単語、会話文、リスニング問題、英作文の模範解答、面接の質問文まで。

音声はアプリの中に入っているため、再生のたびに通信は発生しません。電車の中や電波の届かない場所でも同じように使えます。

会話リスニングでは、大人の男性・大人の女性・子どもを別々の声で読み分けています。誰が話しているかを聞き分ける練習ができます。

■ 覚え方のヒント 390語ぶん

単語や熟語に正解したあと、「覚え方を見る」を押すと解説が出ます。語源、似た形の単語との違い、日本語になっている言い方など、記憶に残るきっかけを用意しました。

例：
・borrow → 持ち帰って借りる側が borrow、貸す側が lend。矢印の向きでペア暗記。
・quiet → 「クワイエット」。音がしない。quite（かなり）とつづりが1文字違いなので書き間違えやすい。
・advice → 「アドバイス」。名詞が advice、動詞は advise（アドバイズ）。

まぎらわしい語ほど、間違えやすい理由まで添えています。

■ 間違えたときにこそ、解説を

不正解のときは、正解だけでなく「なぜ他の選択肢では違うのか」まで表示します。文法問題では、紛らわしい選択肢それぞれについて理由を添えています。

■ 進み具合が見える

トップ画面の「合格への道」で、いま全体のどのくらいが身についているかを確認できます。習得ずみ・練習中・まだ手をつけていない問題の数も一目で分かります。

試験日を設定すると、本番までの残り日数と、1日あたりどのくらい進めればよいかの目安が表示されます。

連続学習日数、獲得XP、レベル、連続正解のコンボも記録されます。

■ 二次面接シミュレーション（おまけ）

一次試験に合格したあとに使う、二次試験のための機能です。本番と同じ流れで練習できます。

カードを20秒黙読 → 声に出して音読 → 質問No.1〜5に口頭で回答（質問は音声で流れます）→ 態度のセルフチェック。

面接カードは32枚。この機能はおまけの位置づけのため、1日1回、動画広告を見ると当日は何度でも練習できます。通信できないときや広告を用意できないときは、そのまま使えます。

なお面接は「合格への道」の集計には含めていません。一次試験の対策だけで100%に到達できます。

■ 広告について

無料でお使いいただくため、広告を表示します。

・学習を1セット終えたときの全画面広告
・二次面接シミュレーションを解放するときの動画広告（見るかどうかは選べます）

問題を解いている最中に広告が割り込むことはありません。

■ 学習データについて

進み具合や正誤の記録は、お使いの端末の中だけに保存されます。会員登録やログインは不要です。氏名やメールアドレスなどをお聞きすることはありません。

録音機能はありません。二次面接シミュレーションは、ご自身で出来を評価する方式です。

データを消したいときは、トップ画面の「学習データを初期化」から、いつでも削除できます。
